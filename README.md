# O Segredo do Farol · Gustavo Aventureiro

Jogo 3D de aventura para crianças, feito a partir da história ilustrada **«O Segredo do Farol»** (autor: Gustavo).

▶️ **Jogar:** https://acsystemrpa.github.io/gustavo-aventureiro/

O Gustavo explora o trilho até ao farol com a família, abre tesouros, corta silvas e transforma nuvens cinzentas em flores com a **Espada da Palavra**. Em cada fase ganha uma força nova da armadura de Deus (Efésios 6) e descobre o segredo do farol: *«Tua palavra é lâmpada para meus pés e luz para meu caminho»* (Salmo 119:105).

## Como jogar

| Aparelho | Andar | Espada / OK | Pausa |
|---|---|---|---|
| TV (comando) | setas | OK | Voltar |
| Computador | setas ou WASD | Enter, Espaço ou clique | Esc |
| Telemóvel / tablet | arrastar o dedo | botão dourado | botão ⏸ |

- Tudo tem voz (síntese do próprio aparelho), por isso serve para crianças que ainda não leem.
- Funciona sem internet depois de aberto. Para jogar offline, descarrega o repositório e abre `index.html`.
- O progresso e o quadro de honra ficam **só neste aparelho**. Nada é enviado.

## Técnica

HTML + JavaScript, sem servidor. Mundo 3D com [three.js](https://threejs.org) (`vendor/three.min.js`, licença MIT), em estilo anime (toon com contorno). Se o aparelho não tiver WebGL, o jogo passa automaticamente a 2D.

Produção: CPIMW (Centro de Publicações da Igreja Metodista Wesleyana, Portugal). Versículos: Nova Versão Transformadora (NVT).
